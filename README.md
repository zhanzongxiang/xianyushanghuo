# 闲鱼素材流水线

从 Telegram API 读取频道压缩包，校验并整理本地素材；可选择本地模拟上传、夸克 CLI/WSL 上传或夸克网页上传。输出待人工审核，不自动发布闲鱼。

## 本地运行与服务器数据

设置页新增“服务器数据”：可配置服务地址、访问令牌、工作空间和同步间隔，
查看同步状态、待同步数量与冲突，并手动同步。默认关闭，原有本地运行方式继续可用。
启用后，频道、频道消息、扫描游标、下载上传记录、中文名称及预览图片同步到独立数据服务；
ZIP/RAR、Telegram 会话、账号凭证、代理与磁盘路径保留本机，下载上传仍使用本机网络。
本地 JSON 继续作为缓存，持久同步队列在断网和重启后补传；其他设备任务只读。
两端同时修改同一记录时，设置页选择冲突采用服务器版本或保留本机版本。
服务端使用 SQLite，默认仅监听回环地址，通过 SSH 隧道或 HTTPS 连接；
部署到 `47.113.126.29` 的步骤见 [部署说明](deploy/README.md)。
第一版仅同步业务数据，不提供云端执行队列；术语表和系统配置继续保留本机。

## 素材工作台

“频道消息”页在 Telegram API 模式下只读取频道主帖中的 ZIP/RAR 消息，不读取评论；
默认保留频道转发帖，可在设置中开启“排除转发帖”。页面单独读取 ZIP/RAR 消息元数据与一张封面，
显示频道消息 ID、文件大小、正文与时间，支持读取更早消息、搜索及勾选下载。点击封面可放大、缩放；
新读取的频道照片优先缓存中等尺寸预览，不使用极小缩略图兜底；
点击放大时补载高清图，显示加载状态并支持失败重试，旧版小图在重新读取频道时尝试更新。
读取列表不会下载压缩包，也不会上传到夸克；选中下载后才进入原有下载任务与完整性校验。
频道列表按频道缓存在输出目录的 `.channel-catalog`，封面保存在 `.channel-previews`；
旧版单文件 `channel-catalog.json` 会在访问对应频道时自动迁移。

下载页展示素材图片、文件名、真实下载进度、速度和失败原因；上传页勾选已下载的 ZIP/RAR
后再上传。右侧可查看大图、来源、校验结果和本地目录，设置、日志、来源频道独立管理。
任务记录刷新后保留，重启时将未结束的任务标记为中断，不显示虚构进度。
图片来自对应附件缩略图或 ZIP 内的图片；没有可用图片时显示文件图标。
夸克网页上传仅显示可确认的阶段，分享链接待确认时不重复发送文件。

设置中的“频道消息每轮读取数量”控制每次读取频道和读取更早消息返回的 ZIP/RAR
消息数量，范围为 1-100，默认 100。数量为 100 时，程序最多检查 1000 条 Telegram
原始消息来筛选频道主帖。读取过程中分批显示消息，不再等待全部封面下载结束；
优先复用已经扫描的相邻消息与高清封面缓存，最多 4 路并行获取新封面。
页面显示连接、消息扫描、封面加载、完成或失败阶段，以及消息数、封面进度与耗时。
扫描和图片请求在同一 API 客户端中并行，消息出现后可立即提交文件下载，不必等待全部封面。
默认同时下载 2 个文件，每个大文件默认 4 路分块；所有文件分块和图片共用最多 8 个媒体请求。
列表预览平时最多 4 路，文件下载期间新后台配图请求降至 1 路，主动查看高清图仍可加载；
已经开始的图片请求会正常完成。文件配图不阻塞频道列表中的文件字节传输。
每次最多选择 20 个文件，队列最多保留 40 个未完成的文件/高清请求，重复提交会被拒绝。
停止任务会取消本轮扫描和媒体任务，保留已读取的消息、完整文件与隔离的非空下载片段。
列表预览等待最多 30 秒，按需高清图最多 90 秒，具体速度仍取决于 Telegram 与代理网络。
“来源频道”统一管理已保存频道，频道消息页顶部下拉框、设置页的来源选择和任务频道筛选均读取这份列表；每个频道独立保存消息缓存、
读取游标和预览图。切换只改变当前查看频道，不会删除其他频道缓存或历史下载任务。
在“来源频道”点击“获取账号频道”，通过 Telegram API 扫描当前账号已加入的广播频道（含归档），
自动合并到已保存列表，保存名称、头像和公开用户名或私有频道 ID。重复获取按频道标识去重更新，
保留自定义名称及本轮未获取到的已保存频道；失败或停止不会清空列表及当前选择。
频道列表保存在输出目录的 `channels.json`，重启后可继续选择和读取消息，无须重新扫描账号频道。
也可手动添加公开频道。私有频道仍需要已授权且有访问权限的账号会话。

## 源码运行（Windows）

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config\test.example.json config\test.local.json
.\.venv\Scripts\python.exe run_pipeline.py --config config\test.local.json --web-ui
```

本地界面仅使用 Telegram API。填写 API ID/Hash 后点击“首次登录 Telegram”，在新终端完成账号授权。夸克网页上传仍需浏览器程序路径；夸克 CLI/WSL 上传需要在设置页填写 CLI 执行参数并先完成夸克 CLI 授权。API Hash、Telegram 会话和夸克 CLI 授权只保存在本机，不会从界面读取接口返回。旧 Web 模式配置需在设置中保存一次以迁移。

设置保存后，API ID 显示已保存的值，API Hash 显示密码掩码，代理地址保持原值。
Hash 留空或未修改时保留旧密钥，不会把掩码当成新密钥保存。
默认 `test.local.json` 的 Telegram API 和网络设置同时保存在
`%LOCALAPPDATA%\XianYuMaterialPipeline\telegram-settings.json`，同一 Windows 用户启动
干净新版时自动恢复。没有本机备份时可从同一项目的旧版本配置迁移；已有账号配置不覆盖，
其他设置和下载目录不迁移。自定义配置文件名不使用这份共享配置。
该文件含本机凭证，不应分享或提交；分发 ZIP 仍使用空凭证模板。

运行配置 `config/test.local.json`、账号会话、下载数据、构建产物和日志只保存在本机，不提交到仓库。`config/test.example.json` 仅包含空凭证和示例值。

## 构建便携版

```powershell
.\build_portable.ps1
```

产物位于 `outputs/XianYuMaterialPipeline_v55_download_acceleration/`，运行其中的 `start_ui.cmd`。此目录需整体保留，不要单独移动 EXE。便携包不包含本机 API 凭证、Chromium 或夸克 CLI；API 模式可选配置 SOCKS5/HTTP 代理和 DC 2 生产地址。API 下载连续无进展或超过总时限时中断并保留非空暂存文件；“停止任务”也会中断当前 API 下载。

### 下载加速

源码依赖和便携包均包含 `cryptg` 原生加解密组件，设置页显示实际组件，启动 API 客户端时也会记录。
可运行 `python run_pipeline.py --download-check`，或便携 EXE 的 `--download-check`，执行不联网的加解密自检。
构建脚本要求已启用 `cryptg` 并显式收集其原生扩展。

设置中的“同时下载文件数”支持 1–2，默认 2；“单文件分块并发”支持 1–8，默认 4，
仅对至少 8 MiB 的 ZIP/RAR 生效。两者独立控制，媒体请求总上限固定为 8。
下载队列共用当前客户端及授权，不复制或并发写入账号会话。停止后等待所有写入结束才隔离片段。
日志记录首字节等待、传输耗时和平均速度，可在同一文件与网络条件下比较代理线路。
本地解密自检不能代表真实网络速度；本版未实现断点续传。

### 下载诊断

新版程序自动在输出目录 `logs/download-diagnostics.jsonl` 保存下载诊断，单个日志最多
5 MiB，另保留 3 份轮转备份。记录每个文件的消息 ID、大小、解密后端、代理主机端口、
媒体 DC、每个分块的排队/等待/写盘耗时、实际 sender 复用情况、进度回调耗时，以及首字节、
平均速度、校验和保存耗时。客户端连接、跨 DC、重连、超时和限流事件另行记录，
不直接归因于某一个文件；日志不记录 API Hash、会话密钥、验证码或文件内容。

“任务记录 → 运行日志”右上角的“导出下载诊断”下载 ZIP，内含结构化日志、
`analysis.txt` 和 `analysis.json`。开始一次真实下载后即可导出，正在下载时也可导出阶段记录。
命令行可执行 `python run_pipeline.py --analyze-downloads sample_data/output/logs` 离线分析，
不读取账号配置、不联网。旧版运行日志无法补出分块耗时，需要在新版中重新下载一次。
报告给出观察和排查方向，不能仅凭分块等待判定代理或 Telegram 服务端限速。

设置页的“下载保存目录”接受绝对路径，保存时检查目录可写，后续下载与预览写入新目录。
原文件不搬迁，历史任务继续按保存时的原目录读取文件与图片；任务运行中不可更改配置。

### 夸克 API 批量上传

安装 `requirements.txt` 后，在“设置 → 上传与存储”选择“夸克 API 批量上传”，
填写已登录夸克网页的 Cookie 和目标目录 FID（根目录为 `0`），保存后点击“检查夸克 API”。
Cookie 从浏览器开发者工具 Network 中 `drive-pc.quark.cn` 请求的 Cookie 请求头复制；
目录 FID 可从该目录的 `file/sort` 请求参数 `pdir_fid` 读取，不是整个网页 URL。
Cookie 保存在本机配置文件；页面只显示“已保存”，留空保存继续保留原值，请勿提交本机配置。

在上传任务中勾选素材后点击上传，一次最多 100 条；同一批次有同名文件时会提示分批核对。
默认同时上传 2 个文件，
设置范围 1 到 3；每个文件依次流式上传分片，按服务器返回的分片大小切分，
失败分片最多重试 2 次。进度显示已传字节、速度、剩余时间及哈希/核对/合并/分享阶段。
可启用“本次下载完成后自动上传”，沿用现有下载完成队列。

流程为 MD5/SHA1 → 预上传 → 哈希提交/秒传 → 分片授权及 OSS 上传 → 合并 →
上传完成通知 → 核对远端文件 → 创建分享。相同名称只有大小和哈希一致时才复用；
远端 FID、任务 ID 和文件哈希随任务保存。合并或分享结果不明确时保留“结果待确认”，
再次上传只核对原文件并补取链接，不发送文件内容。上传前失败可重新上传；
恢复时会使用原上传任务的完成回执找回文件 FID，再在原目标目录内核对文件；
目录列表未提供哈希时，有原任务或已保存 FID 的记录仍可恢复。完成回执中的
Base64 哈希会转换后再与本地哈希比较；无原任务或 FID 的同名文件仍须通过内容校验。
未完成分片不提供跨重启续传。Cookie 过期时需更新，接口变动也可能导致失败。

接口流程参考 QuarkPan 的 `ca311f6eaf3a50374371ad0e6900d85c992c7788`，
适配代码和 MIT 声明见 `xianyu_pipeline/quark_api.py` 与 `third_party/QuarkPan.LICENSE`。
未引入上游 CLI、硬编码的 SHA1 中间状态映射或吞掉合并错误的实现。
这是网页内部接口适配，不是夸克提供的公开上传 SDK；真实账号上传需单独验证。
现有网页和 CLI 上传方式继续可选。

### 中文命名试用

在“上传任务”或“素材库”勾选素材，点击“中文命名”。未勾选时显示当前筛选结果，
最多 100 条。点击“生成候选名”，对照图片和英文原名编辑，再点击“确认并应用到夸克”。
“保存草稿”仅保存候选名；生成译名不会自动修改云端文件。

已用夸克 API 上传的文件按原目录及 FID 改名，并重新生成中文标题的分享链接；
待上传文件保存已确认名称，下次通过夸克 API 上传成功后改名，再创建分享。
保留英文原名、本地文件、频道消息 ID、哈希和云端文件名，改名失败单独显示并可重试，
同名冲突不会覆盖已有文件。版本、模型格式、比例及分卷标识必须保留。

设置中的“中文命名”优先匹配自定义术语和内置作品/角色别名，再匹配模型术语。
已补充 `Steins Gate` / `Steins;Gate` → `命运石之门`、
`Kurisu Makise` / `Makise Kurisu` → `牧濑红莉栖`，支持空格、下划线及连字符分隔。
例如 `Kuru Figure - Steins Gate - Kurisu Makise.rar` 的候选名是
`Kuru 手办 - 命运石之门 - 牧濑红莉栖.rar`；`Kuru` 尚未识别，保留并单独提示。

可选择 MyMemory 在线翻译或仅本地术语。在线模式免密钥，固定已识别的作品、角色和模型术语，
仅将其余原始文本分段发送给翻译服务，有服务配额；原文回传、无有效进展及失败片段保留原文，
成功片段仍然保留，已知术语不交由在线服务改写。
带有已识别作品/角色且只剩一个未知英文词时保留该词，避免对作者、品牌或简称猜测音译。
界面区分术语匹配、机器译名和未识别名称；机器译名不代表语义已经核实。
此版本的作品/角色词库有限，不自动搜索网络或识图；自定义术语每行填写
`英文名称=中文名称`。确认过的完整名称保存在输出目录 `name-memory.json`，
同名文件下次生成时复用。上传、Cookie、账号和压缩包内容不会发送给翻译服务。

### 夸克 CLI / WSL 上传

设置页选择“夸克 CLI / WSL”后，默认按 Windows WSL 方式启动夸克 CLI：

```json
{
  "upload_provider": "quark_cli",
  "quark_cli_mode": "wsl",
  "quark_cli_executable_path": "wsl.exe",
  "quark_cli_wsl_distribution": "Ubuntu",
  "quark_cli_node_command": "node",
  "quark_cli_script_path": "/home/用户名/.quarkclouddrive/scripts/quark-drive.cjs",
  "quark_cli_parent_fid": "",
  "quark_cli_timeout_seconds": 3600
}
```

`quark_cli_parent_fid` 留空时使用 CLI 默认目录；填写目录 FID 后上传到指定目录。程序会读取 CLI 的上传进度，上传完成后自动创建分享链接；若分享链接获取失败，任务会进入“结果待确认”，后续只核对已有文件，不重复上传。官方 CLI、Node.js、WSL 和登录授权不打包进本项目，需在目标电脑单独安装和授权。

API 工作台优先获取压缩包紧邻前一条消息的照片或同组图集，最多 5 张，按消息顺序展示。
图片来源和消息 ID 会保存；相邻位置仅是自动关联规则，不代表已确认图片属于该文件。
中间出现文字、文件、视频、链接预览或另一图集时不跨越；图片失败不阻止下载，依次回退到附件缩略图及 ZIP 内图片。
RAR 无需解压即可显示前置图集；没有 Telegram 消息 ID 的历史本地文件暂不支持该关联。

```powershell
$env:BROWSER_TEST_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe tests\check_workbench_ui.py
.\.venv\Scripts\python.exe tests\check_channel_ui.py
```

更多操作说明、下载故障和 RAR 校验行为见 [README_TEST.md](README_TEST.md)。真实频道下载和夸克上传需在使用者账号与网络环境中验证。
