# Electron 桌面版方案（暂存，尚未实施）

记录日期：2026-10-21。

## 结构

- Electron 显示现有工作台，负责窗口、托盘、目录选择和系统通知。
- 本地 Python 进程负责 Telegram、下载校验、夸克上传和数据库同步。
- Python 后端先单独打包，再随 Electron 一起发布 Windows 安装包。
- 服务器只提供数据库，不运行 Electron、工作台服务或下载上传任务。

## 后续实施范围

1. 桌面入口启动本地后端，检测可用端口、服务就绪和启动失败。
2. 实现单实例，重复启动时显示已有窗口。
3. 关闭窗口进入托盘；真正退出时停止任务、保存队列并关闭后端。
4. 将 Telegram 首次登录的控制台输入改为窗口交互。
5. 将配置、会话、缓存放到用户数据目录，保留用户选择的下载目录。
6. 打包依赖、图标和安装卸载入口，排除个人凭据与历史数据。
7. 窗口只加载本机工作台，界面通过受限桥接调用桌面功能。

桌面打包本身不改变下载协议或下载速度。当前先完成本地程序直连远程数据库，
桌面版保持暂存状态。
